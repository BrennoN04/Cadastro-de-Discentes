# Sistema de Cadastro de Discentes

## Descrição

Este projeto foi desenvolvido como atividade prática da disciplina de Back-End da Web Academy.

O sistema implementa um CRUD (Create, Read, Update e Delete) utilizando Java, JDBC e MySQL para realizar o gerenciamento de discentes.

O objetivo da atividade foi adaptar o sistema de cadastro de produtos apresentado em aula para um sistema de cadastro de discentes.

---

## Funcionalidades

O sistema permite:

- Cadastrar um novo discente
- Listar todos os discentes cadastrados
- Buscar um discente pelo ID
- Atualizar os dados de um discente
- Excluir um discente
- Encerrar o programa

---

## Tecnologias Utilizadas

- Java
- JDBC
- MySQL
- PreparedStatement
- Programação Orientada a Objetos (POO)
